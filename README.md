# Kontivo – iOS-App (Branch `swift`)

- In Xcode öffnen: `ios/Kontivo.xcodeproj` – Schritt für Schritt in [`ios/XCODE-START.md`](ios/XCODE-START.md)
- Aufbau und Regeln: [`ios/README.md`](ios/README.md), [`ios/ARCHITEKTUR.md`](ios/ARCHITEKTUR.md), [`ios/CLAUDE.md`](ios/CLAUDE.md)
- Rechenkern (Swift-Paket, ohne Oberfläche): `ios/KontivoCore`
- Werkzeuge (Prüffälle aus der Web-App erzeugen, Bildvergleich): `ios/Tools`
- Alte Arbeitsnotizen: `ios/docs/archiv`
